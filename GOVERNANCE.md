# Governance

## Overview

umans-gate is a personal-use project maintained by a single developer
([@codegiveness](https://github.com/codegiveness)). There is no formal
governance model, steering committee, or community decision-making process.

## Decision-Making

All decisions — architecture, features, releases, roadmap — are made by the
sole maintainer. There is no voting process. Input from forks and pull
requests is considered but not binding.

## Releases

Releases are published at the maintainer's discretion by pushing a `v*` tag,
which triggers the npm publish workflow. There is no release schedule or
guaranteed cadence.

## Security Disclosures

Security vulnerabilities are handled privately. See
[SECURITY.md](SECURITY.md) for the disclosure process.

# Maintainers

This page lists the maintainers of the umans-gate project. Maintainers have
push access to the repository and are responsible for reviewing PRs, triaging
issues, and guiding the project's direction.

## Current Maintainers

| Name | GitHub | Role |
|------|--------|------|

## Responsibilities

- Review and merge pull requests
- Triage and label issues
- Ensure code quality standards are met (typecheck, lint, tests)
- Maintain the CHANGELOG and release tags
- Enforce the Code of Conduct
- Guide architectural decisions and roadmap direction

## Becoming a Maintainer

Maintainers are added by nomination from existing maintainers after
demonstrating sustained, high-quality contributions:

1. Consistent PRs that pass review with minimal revision needed
2. Helpful participation in issue triage and discussions
3. Understanding of the codebase architecture and conventions
4. Respectful collaboration aligned with the Code of Conduct
